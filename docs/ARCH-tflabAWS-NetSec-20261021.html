db-init-kube-dns:53 · VPC CIDR:5432 · host:80 · world:443One extra hole: Secrets Manager over the NAT, for the master secret.
drill-db-block-egressDeny 0.0.0.0/0:5432Drill and fencing tool: cuts the API from any database (failover, promote, failback).

Why ingress lists world, host, remote-node: the ALB is outside the cluster (world); NodePort traffic forwarded by eBPF arrives from the node it entered (host) or another node (remote-node). Other namespaces (kube-system, chaos-mesh, amazon-cloudwatch) have no policies yet - see the risk register.
